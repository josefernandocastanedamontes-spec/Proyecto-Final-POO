# Proyecto-Final-POO
El Impostor es un juego donde todos conocen una palabra secreta menos uno de los jugadores. El objetivo es descubrir quién es el impostor antes de que logre engañar a los demás. Cada jugador tendrá que dar pistas, sospechar de los otros y tratar de no levantar sospechas. ¿Podrás descubrir al impostor o lograrás engañar a todos?
